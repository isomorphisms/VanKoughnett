# Stable homotopy seminar notes

Independent reading notes for Paul VanKoughnett’s 2021 Stable Homotopy Seminar, expanded with related work by Cary Malkiewich, Anna Marie Bohmann, Sarah Yeakel, Agnès Beaudry, and other researchers.

Start with [`notes/README.md`](notes/README.md). It indexes the seminar notebook, researcher maps, worked examples, user’s guides, source-depth warnings, and acknowledgment ledgers.

## Status and provenance

These are study notes, not seminar transcripts. The notes distinguish direct video observations, course-associated written material, bibliographic inventory, and unverified leads. File numbering follows this notebook’s topics rather than a claimed episode order.

Use the linked recordings, author pages, papers, and public notes as the sources of record. Corrections and more precise source matches are welcome.
